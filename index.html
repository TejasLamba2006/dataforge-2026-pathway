The Synapse That Remembers

An interactive explainer of synaptic plasticity as short-term memory, the mechanism behind Dragon Hatchling (BDH), a brain-inspired Post-Transformer architecture from Pathway (arXiv:2509.26507).

The one falsifiable claim

"A fixed-size recurrent state can process a sequence of unbounded duration without allocating a memory slot per token, but it forgets through interference."

Everything below serves this one sentence. Don't take it on faith: run the two experiments that could break it (section 2), then check where the mechanism lives in BDH itself (section 3). Audience: students who know Transformers and attention. Prerequisite: what a KV cache is. Learning objective: after about 10 minutes, you should be able to state why BDH-style attention needs no growing cache, and what it pays instead.

1 · The playground: teach, distract, recall

Below is a live associative memory made of synapses. The toy model is running in your browser right now. It has n = 24 neurons and a synaptic state σ, a fixed 24×24 matrix of 576 numbers. That matrix is its only memory. Each concept (A, B, C…) is encoded as a sparse pattern over ~6 neurons, which is how BDH encodes meaning on neurons. When the model sees a pair like A→B, it performs a Hebbian write: neurons co-active in the same moment strengthen the synapse between them.

Teach associations

One button writes one pair into σ with the Hebbian rule σ(i,j) ← γ·σ(i,j) + x(i)·y(j)

γ is the forgetting rate (ALiBi-style temporal damping in BDH). Drag it and re-teach: low γ means old pairs fade fast; γ near 0.99 means everything lingers and cross-talk piles up.

Recall

Query the state with a cue pattern. Predict the answer before you click. Comparing against ground truth is what makes the claim falsifiable.

Recall results will appear here. Truth: A→B, C→D, E→F.

2 · Try to break the claim

A claim you can't test is a slogan. Three experiments; each states in advance what observation would falsify it. Run them on the playground above.

ExperimentIf the claim is TRUE you'll seeIf the claim is FALSE you'll see
E1: unbounded stream. Press "⚡ Distract ×24" ten times (240 tokens). The KV-cache counter grows unboundedly; the synaptic-state counter never moves off 576. Memory usage is independent of stream length. If the synaptic counter grew with tokens, the state wouldn't be fixed, and the first half of the claim would be false.
E2: interference. Teach A→B → Recall "A" → Distract ×24 (γ=0.90) → Recall "A" again. Confidence in B collapses or flips after distraction. The fixed state can forget, through cross-talk between overlapping patterns. If recall of B were unchanged (or improved) at every distraction level, forgetting through interference, the second half of the claim, would be false.
E3: stability-plasticity dial. Reset, set γ=0.60, teach A→B, distract ×24, recall A. Then reset, γ=0.99, repeat. γ=0.60: old pair is wiped (fast forgetting). γ=0.99: stale associations persist and contaminate recall (slow interference). No γ is free, and that tension is the claim. If some γ gave both durable memory and clean recall, the stability-plasticity trade-off would be false, and the claim's "but" would be wrong.

Falsification condition for the whole artifact: if recall were perfect at every γ and every load, the "forgets through interference" half of the sentence would be false. The experiments above are arranged so you would catch it.

3 · Where this lives in Dragon Hatchling

The toy above is a didactic reimplementation of BDH's central move: attention reformulated as synaptic memory written by Hebbian learning. In BDH (arXiv:2509.26507, §2) the model is n neurons with a state σ(i,j) living on neuron-neuron edges (synapses), updated by edge-reweighting rules called "the equations of reasoning". The paper's Table 1 rule A(i),B(j)→σ(i,j) means: when neurons i and j are co-active, the synapse strengthens. σ then decays with damping U (ALiBi-style). The paper's Fig. 2 calls this "tension on elastic connectors": pulse activations x, y on nodes, slow synaptic state on edges.

The BDH-GPU state-space recurrence (paper Eq. 4, one layer, LayerNorm not shown)

xt,l := xt,l−1 + (Dxvt,l−1)+   ·   at,l := Στ<t vτ,l−1 xτ,lT Ut−τ xt,l
yt,l := (Dy LN(at,l))+ ⊙ xt,l   ·   vt,l := LN(E yt,l)

The middle term is linear attention with an exponential temporal kernel U, computable recurrently: keep the fixed-size state ρt = γ·ρt−1 + xtvtT, read it out as at = ρtTxt [1, §3.2]. This is the same recurrent collapse used by linear-attention models [3] and fixed-state SSMs [4]. ρ = Eσ is n·d numbers: the compressed synapse matrix never grows with t. That is the first half of the claim, and it holds by construction in the architecture itself.

The second half, forgetting, is also structural. Writes are Hebbian ("neurons that fire together, wire together" [1, §2.2, Table 1]), activations are sparse and non-negative (about 5% of neurons active per token in reported BDH runs [1, §6.4]), and because the state is fixed, new writes must eventually overwrite or dilute old ones. BDH-CQ builds its reasoning loop on this recurrent-memory substrate: inputs continuously update the model's memory at inference time, and adaptation happens in recurrent state rather than weights [2]. BDH's own long-context results report the same regime: strong recent-context recall, fading with temporal distance [1].

The concept is active now: recent papers

  1. [1] Kosowski, Uznański, Chorowski, Stamirowska, Bartoszkiewicz, The Dragon Hatchling: The Missing Link between the Transformer and Models of the Brain, arXiv:2509.26507 (2025). Introduces and relies on the concept: synaptic state σ with Hebbian edge-reweighting rules (§2.2, Table 1), BDH-GPU linear-attention recurrence (§3.2, Eq. 4), monosemantic synapses and about 5% sparse positive activations (§6).
  2. [2] Engdahl, Kosowski, Chorowski, Stamirowska, Uznański et al., BDH-CQ: In-Context Learning with Recurrent Latent Reasoning, arXiv:2608.09888 (2026). Extends the concept: recurrent memory updated continuously at inference; relates contextual memory to fast-weight memory and linear-attention views of contextual association, with additive state accumulation per demonstration.
  3. [3] Yang, Wang, Shen, Gated Linear Attention Transformers with Hardware-Efficient Training, arXiv:2312.06635 (2023). Uses the same fixed-state recurrent attention with a data-dependent gate, which plays the role of our decay dial γ; production-scale evidence that the no-KV-cache regime trains well.
  4. [4] Gu & Dao, Mamba: Linear-Time Sequence Modeling with Selective State Spaces, arXiv:2312.00752 (2023). Tests fixed-size-state sequence modeling at foundation scale; the fixed-state-forgets trade-off is shared machinery (though BDH is not an SSM in the Mamba sense, see section 4).

4 · Limitations & common misconceptions

Three things this explainer does not claim

  • "BDH is an SSM in the Mamba sense." It is not, and the problem statement warns against this. BDH-GPU is its own GPU-friendly formulation built from ReLU-low-rank transformations with linear attention; don't classify it with Mamba-style state-space models.
  • "The playground is BDH." It is a toy model, an independent, didactic reimplementation of one mechanism (Hebbian writes + decay), labelled as such per the track requirements. It uses no official BDH checkpoint (none are public) and reproduces no published benchmark numbers. The BDH module grounds everything in the paper's equations and figures instead.
  • "In-session memory = durable learning." Synaptic state is short-term memory at the timescale of minutes or hundreds of tokens. Whether useful fast state can be consolidated into slow weights is an open research question (BDH paper, §1.3 and Conclusions), not something this artifact demonstrates.

Known failure modes of the toy model itself: with only 24 neurons and ~6-neuron concept patterns, cross-talk dominates after about 15 to 20 overlapping associations; recall degrades gracefully rather than catastrophically; and the decay γ here is a single global scalar, whereas BDH's U can be per-edge.
